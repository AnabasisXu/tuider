# URL RSS/Atom Feed Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When a bare URL is an RSS/Atom feed, the url plugin exposes multi-entry sidebar list with in-feed content/description as body; HTML pages keep the existing single-entry path.

**Architecture:** Stay inside `tuider-plugin-url`. After `http_get`, try `feed-rs` parse; on success with ≥1 entry, build `UrlState { title, items }`. Host already maps multi-entry sources to sidebar. Cache feed raw XML separately from page markdown. No host/ABI/catalog changes.

**Tech Stack:** Rust, `feed-rs` 2.x, existing `reqwest` + `strip_tags`, cargo test on `tuider-plugin-url`, fish for smoke.

**Spec:** `docs/superpowers/specs/2026-07-25-url-feed-design.md`

- [ ] **Step 4: Implement types + parser**

```rust
const ENTRY_TITLE_MAX: usize = 120;

struct FeedItem {
    title: String,
    body_md: String,
    link: Option<String>,
}

/// Returns (feed_title, items). Err if not a feed or zero items.
fn parse_feed_items(xml: &str) -> Result<(String, Vec<FeedItem>), String> {
    let feed = feed_rs::parser::parse(xml.as_bytes()).map_err(|e| e.to_string())?;
    let feed_title = feed
        .title
        .as_ref()
        .map(|t| t.content.trim().to_string())
        .filter(|s| !s.is_empty())
        .unwrap_or_else(|| "Feed".into());
    let mut items = Vec::new();
    for e in feed.entries {
        let link = e
            .links
            .iter()
            .map(|l| l.href.clone())
            .find(|h| !h.is_empty());
        let mut title = e
            .title
            .as_ref()
            .map(|t| t.content.trim().to_string())
            .filter(|s| !s.is_empty())
            .or_else(|| link.clone())
            .unwrap_or_else(|| "Untitled".into());
        if title.chars().count() > ENTRY_TITLE_MAX {
            title = title.chars().take(ENTRY_TITLE_MAX).collect();
        }
        let html_or_text = e
            .content
            .as_ref()
            .and_then(|c| c.body.as_ref())
            .map(|s| s.as_str())
            .or_else(|| e.summary.as_ref().map(|t| t.content.as_str()))
            .unwrap_or("");
        let body_core = if html_or_text.is_empty() {
            String::new()
        } else if html_or_text.contains('<') {
            strip_tags(html_or_text)
        } else {
            html_or_text.to_string()
        };
        let body_md = match (&link, body_core.is_empty()) {
            (Some(u), true) => format!("# {title}\n\n> link: {u}\n\n(no content in feed)\n"),
            (Some(u), false) => format!("# {title}\n\n> link: {u}\n\n{}\n", body_core.trim()),
            (None, true) => format!("# {title}\n\n(no content in feed)\n"),
            (None, false) => format!("# {title}\n\n{}\n", body_core.trim()),
        };
        items.push(FeedItem {
            title,
            body_md,
            link,
        });
    }
    if items.is_empty() {
        return Err("empty feed".into());
    }
    Ok((feed_title, items))
}
```

Adjust field access if `feed-rs` version differs (`Text.content` vs `.as_str()` — fix to compile).

```rust
fn feed_rel(url: &str) -> String {
    // same hash as page_rel but suffix .feed
    let mut h: u64 = 0xcbf29ce484222325;
    for &b in url.as_bytes() {
        h ^= u64::from(b);
        h = h.wrapping_mul(0x100000001b3);
    }
    format!("pages/{h:016x}.feed")
}
```

- [ ] **Step 3: Build state from body**

```rust
fn state_from_body(url: &str, body: &str, content_type: Option<&str>) -> UrlState {
    let try_feed = content_type
        .map(|ct| {
            let c = ct.to_ascii_lowercase();
            c.contains("xml") || c.contains("rss") || c.contains("atom") || c.contains("rdf")
        })
        .unwrap_or(false)
        || body.trim_start().starts_with('<');
    if try_feed {
        if let Ok((title, items)) = parse_feed_items(body) {
            return UrlState { title, items };
        }
    }
    let md = html_to_markdown(url, body);
    let title = first_heading(&md).unwrap_or_else(|| url.to_string());
    UrlState {
        title: title.clone(),
        items: vec![FeedItem {
            title,
            body_md: md,
            link: Some(url.to_string()),
        }],
    }
}
```

```rust
fn http_get(url: &str) -> Result<(Option<String>, String), String> {
    // ... same client ...
    let resp = client.get(parsed.as_str()).send().map_err(map_reqwest_err)?;
    let status = resp.status();
    if !status.is_success() {
        return Err(format!("http {status}"));
    }
    let ct = resp
        .headers()
        .get(reqwest::header::CONTENT_TYPE)
        .and_then(|v| v.to_str().ok())
        .map(|s| s.to_string());
    let text = resp.text().map_err(map_reqwest_err)?;
    Ok((ct, text))
}
```

- [ ] **Step 5: Rewrite open / fetch**

```rust
fn open_url(url: &str) -> Result<UrlState, String> {
    // 1) feed cache
    if let Some(raw) = cache_get(&feed_rel(url)) {
        if let Ok((title, items)) = parse_feed_items(&raw) {
            return Ok(UrlState { title, items });
        }
    }
    // 2) page md cache (legacy)
    if let Some(md) = cache_get(&page_rel(url)) {
        if md.trim_start().starts_with('#') || !md.trim_start().starts_with('<') {
            let title = first_heading(&md).unwrap_or_else(|| url.to_string());
            return Ok(UrlState {
                title: title.clone(),
                items: vec![FeedItem {
                    title,
                    body_md: md,
                    link: Some(url.to_string()),
                }],
            });
        }
        // raw-looking cache: try as body
        return Ok(state_from_body(url, &md, None));
    }
    // 3) network
    let (ct, body) = http_get(url)?;
    let state = state_from_body(url, &body, ct.as_deref());
    // write cache
    if state.items.len() > 1
        || (state.items.len() == 1
            && parse_feed_items(&body).is_ok())
    {
        let _ = cache_put(&feed_rel(url), &body);
    } else if let Some(item) = state.items.first() {
        let _ = cache_put(&page_rel(url), &item.body_md);
    }
    Ok(state)
}
```
